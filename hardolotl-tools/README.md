# أداة مسح الفوتج: Hardolotl

تحوّل ساعات الفوتج الطويلة إلى:
- **صفحات صور** (contact sheets): صورة كل 30 ثانية وعليها التوقيت، عشان تشوف ساعة كاملة في صفحتين.
- **ترجمة** (`.srt`) لكل كلامك وردود فعلك من تراك المايك.
- **لحظات الصراخ والضحك** (`moments.csv`): الثواني اللي صوتك فيها عالي، مع الكلام اللي قلته حولها.
- **`report.md`**: تقرير واحد يجمع كل شي، وفيه أعلى 60 لحظة.

## التثبيت (مرة وحدة، ويندوز)
افتح **Terminal** واكتب:

```
winget install Python.Python.3.11
winget install Gyan.FFmpeg
```

سكّر الـ Terminal وافتحه من جديد، وبعدها:

```
pip install faster-whisper pillow numpy
```

> عندك كرت NVIDIA؟ الترجمة تصير أسرع بكثير على الـ GPU. ولو طلع لك خطأ CUDA، استخدم `--device cpu --model small`.

## الاستخدام
حط كل ملفات الفوتج في مجلد واحد، مثلاً `D:\Hardolotl3`.

**1. اعرف رقم تراك المايك:**
```
python footage_scan.py --probe "D:\Hardolotl3"
```
تطلع لك ملفات صوت `track_0_sample.wav` و `track_1_sample.wav` وغيرها. اسمعها، واللي فيها صوتك بس هو رقم المايك.

**2. شغّل المسح:**
```
python footage_scan.py "D:\Hardolotl3" --mic-track 1
```

النتائج تطلع في `D:\Hardolotl3\scan`.

## خيارات مفيدة
| الخيار | وش يسوي |
|---|---|
| `--interval 20` | صورة كل 20 ثانية بدل 30 |
| `--sensitivity 5` | يطلع لحظات أكثر (الافتراضي 3) |
| `--no-transcript` | بدون ترجمة، أسرع بكثير |
| `--model medium` | موديل أخف إذا جهازك بطيء |

## بعد ما يخلص
ارفع على Google Drive أو أرسل في المحادثة:
- `report.md`
- مجلد `sheets`
- ملفات `.srt`

وأنا أطلع منها سجل الفوتج والقصة والسكربت.

# أداة تحليل الكت: cut_scan.py
تحلل فيديو **منشور وجاهز** (مثلاً Hardolotl #1)، وتطلع لك:
- **كل لقطة في الفيديو:** صورتها، ووقت بدايتها، وطولها بالثانية.
- **إحصائيات الإيقاع:** كم كت في الدقيقة، ومتوسط طول اللقطة، والإيقاع كل 30 ثانية.
- **ترجمة الفويس أوفر** مربوطة بكل لقطة.

```
python cut_scan.py "D:\Exports\Hardolotl1.mp4"
```
النتائج تطلع في مجلد `Hardolotl1_cuts` جنب الفيديو. لو طلعت لقطات أقل من الحقيقي، جرّب `--threshold 0.2`.

## أهم شي: ملف XML من Premiere
افتح بروجكت Hardolotl #1 في Premiere، واختر الـ sequence النهائية، وبعدها:
**File → Export → Final Cut Pro XML**

الملف صغير (نص)، وفيه كل قرار كت سويته: أي جزء من الفوتج الخام أخذته، وكم سرّعته، ووين حطيت كل SFX وكل مزيكا. أرسله لي مع نتائج الأداتين.

# أداة تلخيص الـ XML: xml_summary.py
ملف الـ XML من Premiere كبير، فهذي الأداة تلخّصه لملفات صغيرة. **تشتغل حتى لو الفوتج أوفلاين أو محذوف.**

```
python xml_summary.py "C:\Users\Ligoo\Documents\2024-08-08 11-04-08.xml"
```

تطلع لك مجلد `..._summary` فيه:
- `report.md`: نسبة الاختصار (كم ساعة خام صارت كم دقيقة)، والإيقاع كل 30 ثانية، والسرعات، والإفكتات، وأكثر الميمز والـ SFX والمزيكا استخداماً.
- `timeline_00.md` و `timeline_01.md` وغيرها: كل كلب في الحلقة دقيقة بدقيقة، بعد ما تتفك الـ Nested Sequences.

لو اختارت الأداة sequence غلط، حدد الاسم:
```
python xml_summary.py "...xml" --sequence "2024-08-08 11-04-08"
```
