# أداة مسح الفوتج: Hardolotl

تحوّل ساعات الفوتج الطويلة إلى:
- **صفحات صور** (contact sheets): صورة كل 30 ثانية وعليها التوقيت، عشان تشوف ساعة كاملة في صفحتين.
- **ترجمة** (`.srt`) لكل كلامك وردود فعلك من تراك المايك.
- **لحظات الصراخ والضحك** (`moments.csv`): الثواني اللي صوتك فيها عالي، مع الكلام اللي قلته حولها.
- **`report.md`**: تقرير واحد يجمع كل شي، وفيه أعلى 60 لحظة.

## التثبيت (مرة وحدة، ويندوز)
افتح **Terminal** واكتب:

```
winget install Python.Python.3.11
winget install Gyan.FFmpeg
```

سكّر الـ Terminal وافتحه من جديد، وبعدها:

```
pip install faster-whisper pillow numpy
```

> عندك كرت NVIDIA؟ الترجمة تصير أسرع بكثير على الـ GPU. ولو طلع لك خطأ CUDA، استخدم `--device cpu --model small`.

## الاستخدام
حط كل ملفات الفوتج في مجلد واحد، مثلاً `D:\Hardolotl3`.

**1. اعرف رقم تراك المايك:**
```
python footage_scan.py --probe "D:\Hardolotl3"
```
تطلع لك ملفات صوت `track_0_sample.wav` و `track_1_sample.wav` وغيرها. اسمعها، واللي فيها صوتك بس هو رقم المايك.

**2. شغّل المسح:**
```
python footage_scan.py "D:\Hardolotl3" --mic-track 1
```

النتائج تطلع في `D:\Hardolotl3\scan`.

## خيارات مفيدة
| الخيار | وش يسوي |
|---|---|
| `--interval 20` | صورة كل 20 ثانية بدل 30 |
| `--sensitivity 5` | يطلع لحظات أكثر (الافتراضي 3) |
| `--no-transcript` | بدون ترجمة، أسرع بكثير |
| `--model medium` | موديل أخف إذا جهازك بطيء |

## بعد ما يخلص
ارفع على Google Drive أو أرسل في المحادثة:
- `report.md`
- مجلد `sheets`

وأنا أطلع منها سجل الفوتج والقصة والسكربت.
